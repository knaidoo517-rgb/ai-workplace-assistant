# AI Workplace Assistant

Build a modern, responsive web application called “AI Workplace Productivity Assistant.”

The application must open directly without registration, sign-in, onboarding or user accounts. Do not create authentication, a database or a custom backend.

Use a clean professional SaaS dashboard design with blue, navy, white and light-grey colours. Include a responsive sidebar that collapses into a mobile menu.

SIDEBAR PAGES

Dashboard

Smart Email Generator

Meeting Notes Summarizer

AI Workplace Chatbot

Responsible AI

CORE FEATURES

Smart Email Generator

Allow users to enter the recipient, email purpose, important details, desired outcome and email length. Include Formal, Friendly and Persuasive tone options.

Use AI to generate a unique professional email based on the user’s information. Display an editable subject line and email body. Include Copy, Regenerate and Clear buttons.

Meeting Notes Summarizer

Allow users to paste lengthy meeting notes and optionally provide the meeting title, date and participants.

Use AI to generate:

A concise meeting summary

Key discussion points

Decisions made

Action items

Responsible people

Deadlines

Make all results editable and include Copy, Regenerate and Clear buttons.

AI Workplace Chatbot

Create a modern chat interface where users can ask workplace-related questions. The assistant should help with professional communication, planning, task management, meeting agendas and workplace documents.

Every chatbot answer must be newly generated by AI according to the user’s prompt. Do not use preset, generic, random or hard-coded responses.

AI REQUIREMENTS

Connect the three tools to Lovable’s secure built-in AI integration so responses are genuinely generated by AI. Do not expose or hard-code API keys in frontend code. Do not use fake demonstration responses. If the AI connection is unavailable, display a clear error message instead of a generic response.

Use structured prompts containing the user’s task, context, selected tone, required format and supplied details.

GENERAL REQUIREMENTS

No registration or sign-in

No user accounts

No database

No custom backend

No payment features

Responsive desktop, tablet and mobile design

Editable AI outputs

Working copy, clear and regenerate buttons

Loading indicator while AI generates a response

Clear validation and error messages

Accessible colours and readable typography

Light and dark mode

Do not add unnecessary pages or features

Add this disclaimer below every AI output:

“AI-generated content may contain errors. Review and edit all information before using or sharing it.”
